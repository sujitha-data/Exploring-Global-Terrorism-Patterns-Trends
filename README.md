# Exploring Global Terrorism Patterns & Trends

## 📌 Project Overview

This project analyzes global terrorism data from **2012 to 2022** to identify important patterns and trends in terrorism incidents, fatalities, injuries, and hostages across different countries.

The analysis uses **Exploratory Data Analysis (EDA), statistical correlation, and data visualization** to understand the major trends and relationships in the dataset.

## 🎯 Objectives

* Analyze terrorism incidents over the years.
* Identify countries with the highest number of incidents.
* Analyze fatalities and injuries caused by incidents.
* Compare terrorism trends across countries.
* Identify relationships between incidents, fatalities, injuries, and hostages.
* Visualize important patterns and trends using graphs.

## 🛠️ Technologies Used

## 🔍 Analysis Performed

* Year-wise terrorism incident analysis
* Country-wise incident analysis
* Top 5 countries with highest incidents
* Increasing and decreasing incident trends
* Year-wise top 10 countries
* Fatality analysis
* 2015 country-wise fatality analysis
* Iraq and Afghanistan comparison
* Correlation analysis
* Correlation heatmap

## 📊 Key Insights

* Incidents, fatalities, and injuries show **strong positive relationships**.
* Fatalities and injuries have the **strongest correlation (0.913)**.
* Iraq and Afghanistan recorded **high levels of incidents and fatalities**.
* Overall incidents show a **declining trend in recent years**.
* Hostages have a **weaker relationship** with the other variables.
